# MICROSCOPE
广东农检显微镜像
# train.py
详细代码用法和数据集准备格式在代码注释中，接下来介绍代码的相关功能
1：设置随机种子，确保结果可复现
2：定义数据处理函数：训练集用数据增强提升鲁棒性，验证集仅做确定性变换，避免引入随机因素影响评估
3：引入resnet50预训练模型（另提供了efficientnet_b0，可根据需要切换）
4：定义单轮训练函数和分层 K 折验证集索引生成函数
5：定义验证函数，并按类别统计准确率，宏平均准确率消除类别样本数不平衡的影响，更客观反映模型对各类的泛化能力
6：定义主函数：1.解析命令行参数 → 2. 固定随机种子、设置设备 → 3. 加载数据集并做分层 K 折划分 → 4. 逐折训练（每折独立训练 + 验证）→ 5. 保存每折最佳模型 → 6. 输出 K 折整体结果。
